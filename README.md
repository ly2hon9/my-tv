🎬 拾光影视 · ShiguangTV

AURORA 3.20.2 · 优化稳定版

拾光影视是一款集影视聚合搜索、电视直播、热门影视推荐、在线播放及个人观影管理于一体的多功能影视平台。

采用响应式界面设计，兼容手机、平板和电脑，致力于提供简洁、流畅、便捷的观影体验。

✨ 项目功能特色

🎞️ 影视聚合搜索

* 多影视采集源同时搜索，聚合展示相同影片的不同播放线路。
* 支持电影、电视剧、综艺、动漫独立分类。
* 提供聚合、单源、专区等资源浏览方式。
* 支持综合排序、更新时间排序和线路测速。
* 支持剧集选集、集数排序和自动播放下一集。
* 可在多个播放源之间自由切换。

📺 电视直播

* 支持自定义 M3U 电视直播源。
* 央视频道、卫视频道、其他频道横向分类切换。
* 在直播页面使用顶部搜索框，可以直接查找电视台及其直播线路。
* 在非直播页面搜索时，自动使用影视聚合搜索。
* 支持同一频道的多线路选择与切换。
* 支持 VPS 线路测速与排序。
* 支持 EPG 电子节目单，具体内容取决于节目数据是否可用。

▶️ 影视播放器

* 内置 HTML5 播放器，支持兼容的视频格式及 HLS（M3U8）播放。
* 支持播放、暂停、快进、快退、倍速、音量、全屏和画面比例调整。
* 支持画中画功能（取决于浏览器支持情况）。
* 手机端支持双击左右区域快退、快进，以及点击中间区域播放或暂停。
* 提供复制播放地址及外部播放器快捷入口。
* 切换至其他栏目时停止当前播放，避免后台继续消耗流量。
* 针对 Safari 原生 HLS 和其他浏览器的 HLS.js 播放方式进行兼容优化。

🌟 热门影视推荐

* 接入 TMDB 影视资料，展示真实电影、电视剧信息和海报。
* 热门推荐数据可通过定时 Worker 同步到 Cloudflare D1。
* 支持根据年份、评分和热度等条件筛选影视作品。
* 点击推荐影片后，可从用户已配置的影视源中搜索可播放资源。
* 热门影视资料与实际播放源分离管理。

❤️ 收藏与观看历史

* 支持收藏影视作品及播放线路。
* 自动记录观看历史及播放进度。
* 支持历史记录续播。
* 支持管理个人收藏内容。
* 个人观影数据可通过账号及云端接口保存。

👥 账号与权限管理

* 支持用户登录与注册。
* 支持管理员管理用户账号。
* 支持影视采集源配置、启用与停用。
* 支持用户分组与不同采集源的访问权限管理。
* 支持云端配置保存与订阅源更新。

🎨 界面与交互设计

* 深色影视风格界面。
* 手机、平板、电脑自适应布局。
* 顶部固定导航栏，方便快速切换栏目。
* 搜索框与导航栏整合。
* 支持深色、浅色及自动主题模式。
* 播放器与影视列表适配移动端操作。
* 采用 HTML、CSS、JavaScript 分离的模块化结构，便于后续修改主题和扩展功能。

⚡ 性能与加载优化

* CSS、JavaScript 独立管理与浏览器缓存。
* 通过文件版本标识减少旧缓存造成的界面异常。
* HLS.js 按需加载，降低不必要的初始脚本下载。
* Cloudflare D1 部分配置读取采用批量请求。
* 热门推荐支持云端缓存与本地缓存。
* 减少部分重复请求，提高页面维护和更新效率。

🛠️ 技术架构

技术	主要用途
HTML / CSS / JavaScript	前端页面及交互
Cloudflare Pages	网站部署
Cloudflare Pages Functions	后端 API
Cloudflare D1	配置、账号及个人数据
Cloudflare Workers	定时推荐同步
TMDB	影视资料、海报和热门推荐
HLS.js	浏览器 HLS 播放兼容
M3U	自定义电视直播源

🚀 部署说明

项目推荐使用 GitHub + Cloudflare Pages 部署，并根据实际使用需求配置 Cloudflare D1、相关环境变量和影视数据源。

模块化版本需要保持 HTML、CSS、JavaScript 和 Pages Functions 的目录结构完整。

网站支持自行配置影视订阅地址及 M3U 直播源。相关账号、数据库和密钥应由部署者自行管理。

⚠️ 使用声明

本项目不内置影视视频、付费频道或直播内容，播放资源需要由用户自行配置。

TMDB 提供的影视资料和海报仅用于内容展示和发现，不代表一定存在可用的播放线路。

请遵守相关法律法规及版权要求。第三方影视源、直播源和外部播放器的可用性不由本项目保证。
